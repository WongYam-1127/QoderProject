# WongYam的装机Lab · VOLTA G01

从一台空的 mATX 机箱开始：卡好 IO 挡板，落主板，装 CPU、两条内存、塔式散热器和电源；再在装配台上拼出显卡——底板 PCB、GPU 核心、回流焊、散热鳍片、散热风扇，风扇线留在卡内；整张卡插进 PCIe 插槽，接上 24-pin、CPU 8-pin、显卡供电、CPU 风扇、DisplayPort 与市电线，开机——最后在自己的屏幕上调出属于你的画面。

十一个零件、七根线缆、六道工序，全部由真实几何与规则驱动。

这是完整的本地前端应用，不是视频设计稿或仅能旋转的模型查看器。无账号、数据库、AI 接口、后端、密钥、云端绑定。

## 启动与构建

需要 Node.js 22.18+ 或 24 LTS，以及支持 WebGL 2 的现代浏览器。

```sh
npm ci
npm run dev
```

开发地址：`http://127.0.0.1:4408/`。

```sh
npm run build
npm run preview
```

`dist/` 是已附带的静态构建产物。所有运行素材均使用相对路径，支持放在域名子目录。请使用 HTTP 静态服务，不要直接双击 `index.html` 以 `file://` 打开。开发与预览默认共用端口，运行预览前先停止开发服务；如需并行，可 `npm run preview -- --port 4409`。

## 玩法

1. 点击“开始组装”，爆炸图自然落到开放平台上，机箱立在画面左侧。
2. **平台**：先卡 IO 挡板，再落主板（九颗铜柱定位），然后 CPU、两条内存（A2/B2 组双通道）、塔式散热器与底部电源仓里的电源。依赖顺序由规则强制：主板需要挡板，CPU 与内存需要主板，散热器需要 CPU 和两条内存。CPU 出厂方向旋转 90°，按 `R` 或点击“旋转 90°”，让天青标记对齐。
3. **装卡**：底板 PCB → GPU 核心（同样需要先转 90°）→ 散热鳍片 → 散热风扇。
4. **回流焊**：核心落位后右侧出现回流焊台。按住加热让温度上升，进入 200–275°C 窗口后进度才会累加；接近 275°C 就松手，短按短放把温度留在区间里。超过上限会过热，进度倒退并记录一次损伤。焊点凝固前鳍片压不下去。
5. **卡内接线**：切换到“接线”，`F1 ↔ F2` 把风扇供电端子接回底板 PCB 的针脚。这条线在机身内部，必须在上机之前完成。
6. **上机**：四个显卡组件、焊点与风扇线完成后可以整卡拿起。拖动显卡让金手指对准机箱里的 PCIe 插槽松手，或点击“插入 PCIe 插槽”标记；距离不够会被拒绝。上机后卡扣锁定，内部风扇线不再可改动，主板也不能在卡还插着的时候取出。
7. **外部接线**：卡装好之后机箱侧的接口才存在，依次完成
   - `A1 ↔ A2`：电源 24-pin ATX ↔ 主板供电；
   - `E1 ↔ E2`：电源 CPU 8-pin ↔ 主板左上角 EPS；
   - `G1 ↔ G2`：电源 PCIe 8-pin（12V-2x6）↔ 显卡供电口；
   - `C1 ↔ C2`：主板 CPU_FAN ↔ 散热器风扇；
   - `D1 ↔ D2`：显卡 DisplayPort ↔ 显示器；
   - `M1 ↔ M2`：机箱电源尾座 ↔ 桌面排插。
8. 随时可以尝试电源按钮。条件不足时会列出全部缺项并高亮第一个位置，不会伪造通电。开机按电源灯 → 风扇 → 卡身灯效 → 屏幕背光 → 画面的时序推进。
9. 点亮后用底部滑杆调节**亮度、对比度、清晰度**，清晰度就是屏幕着色器的采样模糊与锐化强度（刻度上的小白点是最清晰的甜点值）。可在短片、渲染负载测试图、色彩校准图之间切换，短片支持播放与暂停。
10. 点击“进入桌面”，镜头进入同一个三维世界。用 `A / D`、左右方向键或屏幕按钮在桌面前、屏幕前和夜窗之间探索；可以开关台灯、开合窗帘。
11. 在屏幕视角点击“坐下观影”或按 `Enter` 进入沉浸视角；按 `Escape` 或“起身看看”返回房间，再从右上角“返回工作台”。
12. 拆件、改线或下机前先关机。选中已装好的零件可“取回工作台”；拆核心会让焊点作废，内部风扇线要先断开才能取风扇，接了插槽侧线缆时显卡取不下来。
13. “重新组装”会复原零件、焊点、线路、机箱内状态、朝向、相机、画面参数与播放进度；只保留用户的声音偏好。

空白处拖动旋转相机，滚轮缩放。拖拽零件或整卡时相机锁定。`Escape` 取消选择或接线。“提示位置”只标出槽位，不会自动装好零件。底部“组件 / 接线”面板顶部有一个可上下拖拽的把手（也可聚焦后按 `↑` `↓` 或 `Home` `End`），用来调节面板高度，内容超出时在面板内部滚动，提示条始终贴在面板上方不被遮住。

### 手机

先点组件栏或场景中的组件，再点对应安装槽；连接线路依次点起点和终点。方向、依赖、回流与上机规则和桌面完全相同。工作台可单指旋转、双指缩放；进入桌面后使用左右按钮切换驻点，点场景中的发光标记互动和观影。竖屏里点选组件后，相机会顺著当前视角滑到它的安装位；切到“接线”时滑到待接线缆两端的接口；四个显卡组件与焊点做完后滑到 PCIe 插槽——准星、端口与卡扣标记都不会留在画面外（横屏与桌面的机位不变）。接口标记只在“接线”页出现，因此竖屏接完卡内的风扇线要先切回“组件”页，`M1` 一类的圆形接口标记不会压在 PCIe 卡扣标记上面；点下线缆的一端后，相机会再滑到另一端，跨度最大的市电线也能连着点完。横向滚动底部组件栏，回流焊台在移动端上浮为独立面板，不依赖 hover。

### 外观工作台与动效

页面外观集中在 `:root` 上的少数自定义属性：`--site-accent`（强调色，默认天青石蓝）被样式表里的按钮、选中态、准星标记、端口热点、滑杆、光晕与文字色反复派生（`color-mix()`），改这一处就能整体换色；`--site-radius` 统一面板、卡片与弹窗的圆角；`--site-space` 缩放内边距；`--site-type` 缩放标题字号；`--site-motion` 是所有过渡时长与动画周期的倍率；系统开启“减少动态效果”时，样式表用一条媒体查询直接关掉 transition 与 animation，三维侧则由 `scene.reduced` 让相机与零件吸附一步到位、首屏不再漂浮。组件面板的高度由把手写入的 `--dock-h` 决定，范围限制在 168px 到视口可用高度之间，提示条与回流焊台始终贴在面板上沿之上。

声音默认关闭，开启后才建立音频上下文并播放轻微开机和运行声音。页面隐藏时暂停影片和无意义渲染。系统“减少动态效果”会减少镜头与零件过渡，不妨碍手动安装。

## 项目结构与 Remix

- `src/config.ts`：品牌、产品、组件名称与说明、安装位置、工作台位置、爆炸位置、初始方向、依赖关系、回流窗口与斜率、上机位置与旋转、接口、线路路线、颜色、机箱与屏幕和桌面相机布局、媒体；`COPY` 集中界面与操作反馈文案。
- `src/state.ts`：集中装配状态、纯规则判定与状态操作。进度由已安装组件、焊点、线路与上机状态计算。
- `src/models.ts`：可编辑的 Three.js 程序化工业模型（显卡四件套、显示器、加热头、排插）与材质、丝印、接口细节。
- `src/platform.ts`：mATX 侧透机箱壳体、主板（铜柱、供电、芯片组、PCIe 与内存槽）、CPU 与散热器、内存条、IO 挡板、ATX 电源与风扇转子。
- `src/desk.ts`：程序化电脑桌、夜间窗景、家具、台灯、窗帘动画与桌面诊断。
- `src/scene.ts`：场景、引导式相机、射线拾取、零件与整卡拖放、吸附过渡、线缆、加热可视化与触控标记。
- `src/projection.ts`：屏幕着色器（模糊 / 锐化 / 亮度 / 对比度 / 暗角 / 扫描线）、视频与程序纹理、开机时序、背光溢光。
- `src/main.tsx` / `src/style.css`：React 界面、回流焊台、组件面板高度把手与独立移动端布局；主色集中在 `--site-accent`（天青石蓝），底色为米白，回流焊相关颜色保持暖色以表达温度。
- `public/media/`：本地影片与独立授权说明。
- `tests/`：规则测试、最初的交互验证及完整浏览器闭环测试。
- `cover/`：本轮闭环里从运行中的站点直接截下的画面——`intro.png` 首屏、`cover.png` 重新点亮后的整机、`bench.png` 通电工作台、`desk-screen.png` / `night-window.png` / `cinema.png` 桌面三视角、`mobile.png` 与 `mobile-desk.png` 竖屏。
- `dist/`：可部署到静态服务的构建产物。

### 更换为其他设备

1. 调整配置中的组件集合、`slot/home/exploded`、`dependencies`、`initialAngle` 与尺寸，再为对应组件修改程序化模型。
2. 配置 `PORTS` 的归属、世界位置与编号，`WIRES` 的允许接口组合、路线与是否位于机身内部。绝不依赖点击次数计算进度。
3. 修改装配距离、方向容差、`SOLDER` 的回流窗口与 dwell、`MOUNT` 的上机位置与旋转。不要因为放大容差来“修好”操作手感。
4. 统一修改品牌文案与颜色；更换影片时把许可清楚的文件放入 `public/media/` 并更新 `MEDIA` 和授权说明。
5. 若改变屏幕位置，必须同步调整 `DISPLAY` 的面板中心、尺寸与溢光点；`imageSweetSpot` 决定清晰度的最佳刻度。
6. 更新规则测试，重新跑桌面、移动端与减少动态效果流程，再重新构建。视频比例当前为 16:9；其他比例需同步调整屏幕尺寸。

## 演示的简化边界

这是**低压装配演示，不是实际电器维修、市电接线、焊接或产品制造指南**。

- 用槽位距离、离散朝向、依赖关系和焊点状态判定，不模拟刚体碰撞、真实热场、焊锡金相或电路电流。
- 机箱按 mATX 侧透结构建模：主板托盘、电源仓、PCIe 与内存槽位、后部 IO 与顶部排风按真实相对关系布置，但不提供螺丝孔位级别的图纸精度，也不模拟走背线。
- 回流焊是温度斜坡与窗口 dwell 的简化模型；过热只记录状态，不会真的损坏零件。
- 曲线管状线缆有明确走线和弯曲，不采用绳索物理。
- 显卡外形借用当代旗舰双穿流散热的设计语言，但品牌与型号 VOLTA G01 完全虚构，模型为原创程序化几何，不代表任何真实产品的电路或结构。
- 画面调节由屏幕着色器的多点采样模糊与拉普拉斯锐化实现，不是显示器的真实电子学。
- 短片是真实本地 MP4，测试图和色彩图案明确标注为程序生成。
- 不支持 WebGL 时显示兼容性说明，不以静态图伪装成功运行。

## 验证

```sh
npm test
```

完整浏览器测试使用 `playwright-core`，不自动下载浏览器，默认调用 Windows 的 Google Chrome；其他系统传入本机浏览器可执行路径。

```sh
CHROME_PATH="C:/Program Files/Google/Chrome/Application/chrome.exe" npm run test:browser
# 可选：TEST_URL=http://127.0.0.1:4409/ TEST_OUTPUT=/tmp/volta-qa
```

测试通过真实鼠标、键盘和触屏输入操作，根据页面的当前状态、几何位置和错误提示逐步行动，并对屏幕区域做像素差分校验亮度、对比度与清晰度的真实效果。`window.__VOLTA__.read()` 只提供脱离内部对象的只读快照，没有通关、安装或修改状态的入口。实际测试范围及局限见 `VERIFICATION.md`。
